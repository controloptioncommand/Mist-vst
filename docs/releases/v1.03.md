## v1.03 — новый дизайн

- Темы **Oxygen** (светлая) и **Rubber** (тёмная), можно следовать системной теме macOS
- Стеклянный тулбар, стекло только на функциональных элементах, никаких теней
- Главный вид по умолчанию — **Scope**: плотная волна, цвет по громкости от −24 до 0 дБ, направляющие −6 и −12 дБ, легенда
- Карточки операторов: роль цветом (carrier / modulator), волна в цветах громкости
- Fine стал двуполярным (−50…+50%), у графика wavetable — следы прошлых положений Position
- Страница **About** и игра с пиксельной совой
- Кольцо фокуса, подписи для скринридера, учёт «Уменьшить прозрачность» и «Уменьшить движение»
