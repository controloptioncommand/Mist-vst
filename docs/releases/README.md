# Патчноуты

У каждой версии — свой файл `<версия>.md` (например, `v2.md`). Текущая версия задаётся в файле `VERSION` в корне репозитория.

Как выпустить новую версию:
1. Поменять `VERSION`: минорный апдейт — v2.1 → v2.2 → … → v2.10 → v2.11, мажорный — v3.
2. Добавить `docs/releases/<версия>.md` с патчноутом (например, `v2.2.md`).
3. Закоммитить в `main` — сборка сама опубликует релиз с архивом и этим текстом.

Без файла патчноута сборка остановится.
